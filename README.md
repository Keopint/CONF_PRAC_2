# Dependency Graph Visualizer (Variant 18)

## Общее описание
Инструмент командной строки для визуализации графа зависимостей менеджеров пакетов.
Текущая версия: **Этап 3 (Основные операции)**.

На данном этапе реализован обход графа зависимостей с помощью алгоритма BFS (поиск в ширину) без использования рекурсии. 
Программа корректно обрабатывает циклические зависимости (не уходит в бесконечный цикл) и поддерживает ограничение максимальной глубины анализа.

## Описание функций и настроек

Приложение поддерживает следующие опции командной строки:

* `--package` (строка) — Имя анализируемого пакета (обязательный параметр).
* `--repo` (строка) — URL-адрес репозитория (например, `https://pypi.org`) или путь к локальному файлу тестового репозитория (обязательный параметр).
* `--test-mode` (флаг) — Режим работы с тестовым репозиторием. Если флаг установлен, параметр `--repo` воспринимается как путь к текстовому файлу.
* `--ascii-tree` (флаг) — Режим вывода зависимостей в формате ASCII-дерева *(будет реализован на Этапе 5)*.
* `--max-depth` (целое число) — Максимальная глубина анализа зависимостей (обязательный параметр, от 1 до 100).

### Формат файла тестового репозитория
Для режима `--test-mode` используется текстовый файл (например, `test_repo.txt`). 
Формат строки: `ПАКЕТ: ЗАВИСИМОСТЬ1 ЗАВИСИМОСТЬ2`.
Имена пакетов должны состоять из больших латинских букв.
Пример:
```text
A: B C
B: D
C: D E
D: A
