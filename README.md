# Dependency Graph Visualizer (Variant 18)

## Общее описание
Инструмент командной строки для визуализации графа зависимостей менеджеров пакетов.
Текущая версия: Этап 2 (Сбор данных).

## Описание функций и настроек
Приложение поддерживает следующие опции командной строки:
* `--package` (строка) — Имя анализируемого пакета.
* `--repo` (строка) — URL-адрес репозитория (например, `https://pypi.org`) или путь к файлу тестового репозитория.
* `--test-mode` (флаг) — Режим работы с тестовым репозиторием.
* `--ascii-tree` (флаг) — Режим вывода зависимостей в формате ASCII-дерева.
* `--max-depth` (целое число) — Максимальная глубина анализа зависимостей.
